# laravel-boat

Projet réalisé pour découvrir Laravel et PHP.

## Présentation

laravel-boat est une application de réservation de bateaux. Les utilisateurs peuvent consulter les bateaux disponibles sur les sept prochains jours et réserver un créneau le matin ou l'après-midi.

Un espace administrateur permet de consulter les réservations et de gérer la position des bateaux, notamment ceux présents ou sortis du hangar.

## Technologies

- PHP 8.3 et Laravel 13
- SQLite par défaut pour la base de données
- Blade pour les vues
- Tailwind CSS et Vite pour l'interface et les ressources front-end
- Laravel Fortify pour l'authentification
